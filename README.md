# Контрольная работа №2
Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap».

## Описание
FitZone — сайт современного фитнес-клуба с тренажёрным залом, бассейном, групповыми занятиями и персональными тренировками. Посетители могут узнать о клубе, посмотреть расписание, выбрать абонемент и оставить заявку на пробное занятие.

## Используемый фреймворк
Bootstrap 5.3.3 (CDN).

## Структура проекта
- `index.html` — главная страница (hero, преимущества, направления)
- `catalog.html` — расписание занятий (сетка карточек)
- `product.html` — страница абонемента с характеристиками и FAQ
- `order.html` — форма заявки на пробное занятие
- `css/custom.css` — дополнительные стили
- `images/` — изображения

## Реализованные компоненты Bootstrap
- `navbar` — адаптивная навигация с мобильным меню
- `card` — карточки направлений и абонемента
- `btn`, `btn-primary`, `btn-outline-primary` — кнопки
- `badge` — метки «Хит», «Новинка», «Скидка»
- `alert` — информационные сообщения
- `modal` — модальное окно быстрой записи
- `accordion` — блок частых вопросов
- `form-control`, `form-select`, `input-group`, `form-check` — форма заявки
- `breadcrumb` — хлебные крошки
- `table`, `table-striped` — таблица характеристик
